System Design

The 6-Role Collaborative Security Team

Inspired by advanced agentic security architectures, VulScanAgent uses specialized personas with strict separation of duties.

🎯 ScanStrategist
Assesses repository technology stack, frameworks, manifests, and tailors the scanning attack vectors.
🛠️ FixArchitect
Synthesizes surgical AST patches constrained within XML quarantine delimiters to eliminate code injection.
🧐 SecurityReviewer
Critiques proposed fixes against MITRE ATT&CK, MITRE D3FEND, and OWASP Top 10 standards before applying to disk.
🧪 TestRunner & Verifier
Executes unit tests in isolated runtime sandboxes and synthesizes custom regression tests for patched vulnerabilities.
🩺 ErrorDiagnostician
Parses runtime test failure stack traces, diagnoses regressions, and prescribes corrections back to the Architect.
📝 PRAuditor
Drafts formal Pull Request audit reports with test execution badges, CVE mapping, and rollback instructions.
